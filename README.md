# مكتبة دبلوم القانون الخاص الرقمية — دليل الاستخدام

## تشغيل الموقع — طريقتان

### 1) ملف واحد مستقل: `مكتبتك-الذكية.html`
الموقع **كله في ملف HTML واحد** (الكتب التسعة كاملة + البحث + القارئ + لوحة الإدارة + التصميم + الخطوط مدمجة). انسخه على موبايل أو أي جهاز وافتحه بأي متصفح — **يعمل بدون سيرفر وبدون إنترنت**. حجمه ~7.7MB لأنه يحتوي 1,414 صفحة نص كاملة.

### 2) نسخة الاستضافة (مجلد site/)
للنشر على GitHub Pages / Netlify / أي سيرفر ملفات: ارفع محتويات مجلد `site/` وافتح `index.html`. نفس الوظائف، مع ملفات منفصلة (أسرع في التحميل الأولي).

## الصفحات
| الصفحة | الوظيفة |
|---|---|
| `index.html` | الرئيسية: بحث ذكي + مواعيد الامتحانات + جدول المحاضرات + المقررات + الكتب + سؤال عشوائي |
| `book.html?id=…` | قارئ الكتاب: النص كاملًا بتصميم خاص لكل كتاب، فهرس، تنقل بين الصفحات، بحث داخل الكتاب مع تظليل، علامات مرجعية — **اطلاع فقط** (لا يوجد زر تحميل، والنسخ مسموح) |
| `search.html?q=…` | نتائج البحث: عبارات، كلمات، أرقام صفحات، «عناصر …»، «موضوع … من صفحة كام» |
| `admin.html` | لوحة الإدارة (بدون كلمة مرور) |

## البيانات
- `library/book-*.json` — نص كل كتاب (مستخرج من الـ PDF الأصلي؛ الصفحات التالفة أُعيدت قراءتها بـ OCR عربي، وكل صفحة موسومة بطريقة استخراجها `pdf-text` أو `ocr`).
- `library/search-index.json` — فهرس البحث الموحد (تُحمّله الصفحة تلقائيًا).
- `data/site.json` — البيانات المشتركة التي تتحكم فيها من لوحة الإدارة: المحاضرات، الامتحانات، المقررات، بنك الأسئلة.

## لوحة الإدارة (بدون كلمة مرور)
1. **جدول المحاضرات**: أضف اليوم/المادة/الوقت/القاعة/المحاضر — يظهر فورًا في الرئيسية.
2. **الامتحانات**: الاسم + المقرر + التاريخ + الساعة + الثواني — عدّ تنازلي حي مرتب بالأقرب، وحالات «الامتحان بدأ / انتهى الامتحان».
3. **المقررات**: اسم المقرر + مدى الصفحات من كتب المكتبة.
4. **بنك الأسئلة**: اختيار من متعدد / مقالي، مربوط بكتاب وموضوع وصفحة.
5. **الكتب**: تعديل العنوان/المؤلف/القسم + إدارة الموضوعات وعناصرها (تظهر عند سؤال «عناصر …» في البحث).
6. **إضافة كتاب**: رفع PDF يُحوَّل داخل المتصفح (استخراج نص + كشف تلقائي للنص التالف + OCR عربي للصفحات المصابة فقط) ثم يصبح قابلًا للبحث فورًا.

### مشاركة التعديلات مع كل الزوار
تعديلاتك تُحفظ في متصفحك وتظهر فورًا. لتظهر **أمام الجميع**: من لوحة الإدارة ← «تصدير البيانات» ← استبدل `data/site.json` على الاستضافة بالملف المُصدَّر (أو استورد الملف من أي جهاز آخر).

## الكتب المتضمَّنة (9 كتب بعد حذف المكرر)
1. الإثراء التكنولوجي لعقود الترخيص (كتاب الطلاب) — 283 صفحة
2. السوابق والمبادئ القضائية المحلية والدولية في مجال حقوق المؤلف — 159 صفحة
3. الأوامر على عرائض في قانون الملكية الفكرية — 63 صفحة *(OCR)*
4. اتفاقية تريبس (TRIPS) — 37 صفحة
5. تنازع القوانين في مجال الالتزامات غير التعاقدية — 299 صفحة *(OCR كامل — طبقة النص الأصلية كانت تالفة)*
6. قانون الأونسيترال النموذجي للتحكيم التجاري الدولي (1985 بتعديلات 2006) — 56 صفحة *(OCR — الملف الأصلي بترميز مكسور)*
7. الاستدانة: دراسة في أزمة ديون الأفراد ومعالجتها القانونية — 279 صفحة *(OCR — الملف الأصلي ممسوح ضوئيًا بدون نص)*
8. نظرية العقد في الفقه الإسلامي (شريعة إسلامية اختياري) — 184 صفحة *(OCR)*
9. مراجعة مرافعات 2025 — 54 صفحة

**المكرر المحذوف:** `الاستدانة.pdf`، النسختان المكررتان من «السوابق والمبادئ» و«القانون الدولي الخاص».

## الخصوصية والأمان
- كل المعالجة داخل المتصفح — لا تُرسل الكتب أو البيانات لأي خادم خارجي.
- نصوص الكتب بيانات للعرض فقط (لا تُنفَّذ كأوامر)، والمحتوى المرفوع لاحقًا يُنقّى قبل الحفظ.
